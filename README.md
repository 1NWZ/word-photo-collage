# 词图拼贴 · Word Photo Collage

将多张照片编排成一张完整的 3:4 图文拼贴。保留原图像素，用短词、矩形照片和留白建立阅读节奏。

## 三种随机排版

| 模式 | 风格 |
| --- | --- |
| `photo-full` | 照片铺底，多行词图左右交替，纵向展开 |
| `photo-cluster` | 照片铺底，词图紧凑聚集，周围留白 |
| `solid-type` | 纯色背景，大小文字穿插照片，少量手绘 |

默认每种模式概率为三分之一；也可以指定模式。两张照片会自动简化，多张照片默认全部使用。底图和裁剪位置由执行技能的模型根据画面内容选择。

## 使用

把本目录放到 `~/.codex/skills/word-photo-collage/`，上传待制作的照片，然后输入：

> 用 $word-photo-collage 做一张随机风格的图文拼贴。

或指定“照片底饱满排版”“照片底聚集排版”“纯色文字拼贴”。默认输出一张 1080×1440 PNG。

## 渲染脚本

需要 Python 3.9+ 和 Pillow：

```sh
python3 -m pip install -r requirements.txt
python3 scripts/layout.py input.json collage.png --layout-out layout.json
```

模型一次看图后提供主体保护框和短词，三种可调整的代码模板自动安排网格、裁剪与文字；它不自动识别主体。格式见 [模板输入](references/templates.md)，高级精调见 [渲染规格](references/render-spec.md)，完整工作流见 [SKILL.md](SKILL.md)。字体使用运行环境中可用的字体文件，不随包分发系统字体。

已验证三种模式渲染、两图适配、裁剪比例与文字越界拒绝，并使用一组五张照片进行了真实成片检查。自动边界检查不能替代视觉检查。

## 素材

本仓库不包含第三方参考图片、私人测试照片或私人测试成片。风格分析仅用于解释排版方法；使用者应自行提供有权使用的素材。

默认生成流程：一次看图、一次模板排版、一次成片检查；仅按所选模式查阅分析，运行缺依赖时再安装，最终直接交付图片。模板保全主体保护框，并限制底部标题，减少截脸、散乱对齐和视觉下坠。
